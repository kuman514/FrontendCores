# HTML

## 시맨틱 태그
- 기능 자체는 div나 span과 동일하지만, 의미를 부여함으로써 웹페이지의 구조를 쉽게 알 수 있도록 만든 태그.

### 왜 시맨틱 태그를 사용하는가?
- 페이지의 접근성과 가독성이 향상된다.
- 페이지를 조금 더 명확하고 직관적으로 설계할 수 있다.
- 검색 엔진 최적화에 도움이 된다.

### 시멘틱 태그 종류
- `<main>` 태그
- `<nav>` 태그
- `<article>` 태그
- `<section>` 태그
- `<aside>` 태그
- `<header>` 태그
- `<footer>` 태그
- `<figure>` 태그와 `<figcaption>` 태그
- `<details>` 태그

## ARIA 속성
- ARIA 속성이란?
  - ARIA(Accessible Rich Internet Application)는 접근성이 높은 인터넷 앱을 의미함
  - ARIA 속성은 전세계 모든 사용자가 웹 사이트에 접근할 수 있도록, 스크린 리더나 키보드 탐색 등의 보조 장치로도 웹 시이트를 이용하게 만들어줄 수 있게 만드는 속성이다.
- 왜 필요한가?
  - 전세계에서 10억 명 이상의 사람들이 어떤 형태로든 장애를 가지고 있으며, 많은 사람들은 웹 사이트를 이용하기 위해 스크린 리더, 음성 제어, 키보드 탐색 등의 보조 기술에 의존한다.
  - ARIA를 구현하지 않는다면, 이러한 사용자들에게는 열심히 만든 웹사이트조차 아예 사용할 수 없는 앱이 된다.
- 사용 시 주의사항
  - 시멘틱 HTML 태그 사용이 가장 우선순위.
  - 시멘틱 HTML 태그로 접근성을 채울 수 없을 때 ARIA 속성을 사용한다.
  - 상태를 동기화 상태로 유지한다.
  - 상호작용 가능한 콘텐츠를 숨기지 않는다.
  - 텍스트 콘텐츠가 이미 접근이 가능한 경우 등등 ARIA 속성 없이도 접근이 될 때, 일을 굳이 복잡하게 만들 필요는 없다.
  - 역할 충돌을 피해라.
- 자주 사용하는 ARIA 속성
  - aria-label, aria-expanded, aria-hidden, aria-live 등등
